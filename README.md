# 📦 Supply Chain & Inventory Analysis – Power BI Dashboard

An interactive **Power BI dashboard** built to analyze and optimize inventory management across multiple warehouses.

This project helps businesses reduce **stock-outs, overstocking, and holding costs** using data-driven insights and KPI monitoring.

---

## 🚀 Problem Statement

A manufacturing company manages inventory across multiple warehouses and faces:

- Frequent **stock-outs** causing delayed deliveries
- **Overstocking** increasing holding costs
- Manual inventory decisions without analytics

The goal is to use **Power BI + DAX** to monitor stock, identify risks, and support smarter replenishment decisions.

---

## 🎯 Objectives

- Monitor stock levels across warehouses
- Identify low-stock and overstocked products
- Optimize reorder planning
- Improve inventory turnover
- Reduce holding costs
- Provide actionable supply chain insights

---

## 📊 Dashboard Features

### 🔹 Inventory Overview
- Total Stock Quantity
- Total Products
- Total Warehouses
- Current Inventory Value
- Stock by Category
- Stock by Warehouse

### 🔹 Stock Health Analysis
- Low / Optimal / Excess stock classification
- Reorder point monitoring
- Shortage detection
- Critical items list
- Slow-moving products

### 🔹 Performance KPIs
- Inventory Turnover Rate
- Sales vs Stock trends
- Holding cost indicators
- Restock recommendations

---

## 📈 Key KPIs

| Metric | Description |
|--------|------------|
| Stock Level | Current inventory quantity |
| Reorder Point | Minimum stock threshold |
| Inventory Turnover | Stock movement efficiency |
| Stock Status | Low / Optimal / Excess |
| Shortage Count | Number of low-stock items |
| Holding Cost | Cost of storing inventory |
